# OneMapas OS 0.1.0 (beta)

Pasta desta versão da ISO. O GitHub não aceita arquivos acima de 100 MB no repositório, por isso:

- o arquivo `.iso` vai para os **Releases** do GitHub (tag `iso-beta-0.1.0`);
- aqui ficam o `info.json` e o `.sha256` gerados pelo build;
- o `ISO/manifest.json` é atualizado sozinho com o link de download, o tamanho e o SHA-256.

Para gerar: GitHub > Actions > **Construir ISO** > Run workflow (canal `beta`, versão `0.1.0`).
